# Portfolio - Nathan Mourat

Site statique : HTML, CSS, JavaScript. Three.js (CDN) pour la carte electronique 3D.

## Mise en ligne sur GitHub Pages

1. Creer un depot public nomme `<ton-pseudo>.github.io`
2. Deposer le contenu de ce dossier a la racine du depot (index.html, img/, .nojekyll)
3. Settings > Pages > Source : branche `main`, dossier `/ (root)`
4. Le site est en ligne sur https://<ton-pseudo>.github.io en quelques minutes

## Fichiers

- `index.html` : page complete (structure, styles, script)
- `img/` : photos des projets
- `.nojekyll` : desactive le traitement Jekyll de GitHub Pages
